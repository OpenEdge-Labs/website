About OpenEdge Labs

OpenEdge Labs is a community that publishes free and open-source software. This site lists its projects and explains how to get, verify and contribute to them.

Licence policy

  • Both current projects, wEdge and APIEdge, are licensed under the Apache License 2.0. The source of this website is Apache-2.0 as well.
  • Third-party components keep their own licences; each project documents them in its repository.
  • Nothing on this site implies endorsement by, or affiliation with, any other organisation.

How a project joins

This is a proposal that the maintainers have not yet formalised. A project can ask to be listed by opening an issue in the website repository with a link to its public repository. We would expect an OSI-approved open-source licence (Apache-2.0 preferred), public source and issue tracker, a security policy with a private reporting channel, and release files that can be verified. The maintainers decide.
