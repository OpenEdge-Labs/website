Get involved

Everything happens in public on GitHub.

Ask a question or report a problem

Open an issue in the project's tracker: wEdge issues, APIEdge issues, or issues for this website. Say which version you use, your operating system, and the steps that reproduce the problem.

Suspected security problems are different: do not open a public issue. See Security.

Contribute code, tests or documentation

Fork the repository, make your change on a branch and open a pull request. Under section 5 of the Apache License 2.0, a contribution you submit is licensed under the same license unless you state otherwise. A maintainer reviews every pull request before it is merged.

Code of conduct

No written code of conduct is published yet in the projects or on this site. Until one is, we ask everyone to be respectful and to keep discussion on the technical subject.

Where to start

  • Run the software and tell us what was unclear in the install guide.
  • Improve documentation or fix a typo.
  • Pick an open issue in a project you use.
