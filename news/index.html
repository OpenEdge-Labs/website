wEdge 0.2.0 released

3 November 2026

wEdge 0.2.0 brings a new Windows installer, an admin page with administrator logins, and the container image on GitHub Packages. The project now lives at github.com/OpenEdge-Labs/wedge.

New Windows installer

  • Asks for the install, web application and configuration folders, the web port, the admin port and an administrator account.
  • Finds an older wEdge and offers to upgrade it or to uninstall it and install fresh.
  • Adds Start menu shortcuts for service control, configuration editing, the admin page, folders, the user guide and uninstall.
  • Checks the choices on each dialog page before installing anything.

Admin page and accounts

  • Administrator accounts turn the admin listener into a status page (version, uptime, connections, listeners, virtual hosts, upstream health) with a reload button; every admin request then needs a login.
  • Only Argon2id password hashes are stored; five failed logins lock the address out for five minutes.
