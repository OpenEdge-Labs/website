wEdge

A web and application server in Rust: static sites, TLS, reverse proxy and metrics in one memory-safe binary, with safe defaults.

Latest release: v0.2.0 (3 November 2026). Licence: Apache-2.0.

Release v0.2.0Source on GitHubIssues

Features

  • HTTP/1.1 and HTTP/2, with limits on headers, URIs, connections and every timeout.
  • Static files: virtual hosts, ETag and Last-Modified, byte ranges, pre-compressed Brotli and gzip, path traversal protection, no directory listing.
  • TLS with rustls: a certificate per virtual host by SNI, TLS 1.2 and later only, HSTS, HTTP to HTTPS redirects, security headers.
  • Reverse proxy: round-robin upstreams with health checks, safe forwarding headers, body limits, timeouts.
  • Operations: access and error logs (text or JSON), Prometheus metrics, hot configuration reload, systemd, OpenRC and Windows service.
  • Configuration: one wedge.toml plus conf.d/, validated against a JSON Schema before use; secrets only by reference (env: or file:).
  • Debug capture: an opt-in log of every request at each layer.

Version 0.2.0 adds a new Windows installer and an admin status page with administrator logins; see the release news.

Quick start

mkdir -p site && echo '<h1>Hello</h1>' > site/index.html
cat > wedge.toml <<'EOT'
[server]
listen = ["127.0.0.1:8080"]
default_vhost = "site"

[[vhost]]
name = "site"
root = "site"
EOT
wedge run -c wedge.toml

How to verify a download

Every release file has a Sigstore signature (<file>.sigstore.json) and, except the public key, is listed in SHA256SUMS and has a GitHub build provenance attestation. The .deb and .rpm packages are also GPG-signed.

sha256sum --ignore-missing -c SHA256SUMS
gh attestation verify <file> --repo OpenEdge-Labs/wedge
cosign verify-blob <file> --bundle <file>.sigstore.json \
  --certificate-identity-regexp '^https://github.com/(OpenEdge-Labs|alinganpatra20004)/wedge/' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com

Releases after 0.1.1 use the newer Sigstore bundle format; cosign 3 verifies them, and cosign 2.4 or later needs --new-bundle-format. Details, including the GPG fingerprint, are in the security policy.
